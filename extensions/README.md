# Extensions
Extensions are placed into the `~/.config/touchkio/extensions` folder and loaded on startup, see the [Extensions](https://github.com/leukipp/touchkio#extensions) section for details.
Have a look at the [example.js](https://github.com/leukipp/touchkio/blob/main/extensions/example.js) file to get started.

## Public extensions
Extensions listed here are maintained by the community and are **not officially supported**, review the code before installing them.

| Name                                                                             | Description                                                                |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| [touchkio-motion-extension](https://github.com/rtm516/touchkio-motion-extension) | Motion sensor fed by the [motion](https://motion-project.github.io) daemon |

To add your extension, open a pull request that adds a row to the table above.
